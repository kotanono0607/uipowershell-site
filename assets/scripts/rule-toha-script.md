# 台本：ルール（判定）ってなに？（用語シリーズ#6・深掘り版）

- 位置づけ：1動画＝1概念の深掘り。M1の三つの操作「見る・打つ・確かめる」の、**確かめる**を担う技術＝ルール（判定）を解く。見る=OCR / 打つ=RPA に続く三部作の完結。
- 題材軸：転記したデータの確認（抜け・桁・重複チェック）
- 1メッセージ：**ルール＝「こうなら、こうする」を決めておく条件。機械が同じ基準でブレずに判定する。ただし決めた条件しか見ない**
- 狙い：初心者に用語を教える
- 尺：約2:00〜2:15（6シーン）／ナレーター：VOICEVOX ずんだもん（speaker 3）
- POV／持論：**「決まった観点のチェックを、人の集中力に頼るのは限界がある」**
- 取材ベース：転記後の確認＝目視で気合い・ダブルチェック／集中が切れると見落とす。
- 深さ担保：定義（IF/THEN）＋例（具体3つ）＋限界（想定外は素通り）を必ず入れる。

---

## S1｜痛み（図解 rule-01）
- テロップ：その「確認」、毎回 目視で気合いですか？
- ナレーション：入力した何十件を、目視で一件ずつ確認する。抜けてないか、桁は合ってるか、ダブってないか。でも、集中が切れた瞬間に、見落としは起きる。

## S2｜用語の登場（rule-02）
- テロップ：今日は「確かめる」を肩代わり
- ナレーション：見て、打って、確かめる。この最後の、確かめるを、肩代わりするのが、ルール、判定です。

## S3｜定義（中心図解 rule-03）
- テロップ：ルール＝「こうなら、こうする」を決めておく
- ナレーション：ルールとは、こうなら、こうする、と、あらかじめ決めておく条件のこと。機械が、その条件どおりに、良いか悪いかを、自動で判定します。

## S4｜仕組み＝具体例（rule-04）
- テロップ：条件（IF）→ 処理（THEN）
- ナレーション：たとえば、金額が空欄ならエラー。合計が一致しなければ警告。日付の形式が違えば、弾く。決めた条件なら、何件でも、同じ基準で、ブレずに判定できます。

## S5｜限界（rule-05）
- テロップ：ルールは「決めた条件しか見ない」
- ナレーション：ただし、ルールは、決めた条件しか見ません。想定していないパターンは、素通りしてしまう。だから、条件をどう決めるか、そして見直すかが、命。複雑な判断は、AIや人に任せます。

## S6｜行動喚起（締め rule-06）
- テロップ：まず「毎回おなじ観点のチェック」を1つ
- ナレーション：まずは、自分の確認作業で、毎回おなじ観点でチェックしている所を、ひとつ。それは、ルールにできます。気合いで見る確認から、卒業しましょう。
