# 台本：ルール（判定）ってなに？（用語シリーズ#6・実演版）

- 脱・概念の実演版。条件を決める→50件をはじく→桁違いはすり抜ける、を「やって見せる」。7シーン。
- 1メッセージ：ルール＝決めた条件で自動判定。同じ基準でブレないが、決めた条件しか見ない。

## S1（ld-01）
- テロップ：その確認、目視で気合い？
- ナレーション：入力した何十件を、目視で、一件ずつ確認する。でも、集中が切れた瞬間に、見落としは起きます。
## S2（ld-02）
- テロップ：「確かめる」を機械に
- ナレーション：この、確かめるを、機械に肩代わりさせるのが、ルール、判定。やって見せます。
## S3（ld-03 実演①）
- テロップ：まず、条件を決める
- ナレーション：まず、条件を決めます。金額が空欄ならNG。合計が明細と合わなければNG。日付の形式が違えばNG。こうならだめ、を、あらかじめ。
## S4（ld-04 実演②）
- テロップ：50件にかける → はじく
- ナレーション：50件に、かけてみます。47件はOK。そして、3件をはじいた。金額が空欄、合計が不一致、日付が、2026年13月。同じ基準で、ブレずに判定できました。
## S5（ld-05 実演③）
- テロップ：桁違いは、すり抜ける
- ナレーション：でも、これは、通ってしまう。正しくは、125万円。なのに、12万5千円、と桁を間違えても、空欄でも、形式違いでもないから、ルールは見抜けません。
## S6（ld-06）
- テロップ：決めた条件しか見ない
- ナレーション：そう、ルールは、決めた条件しか見ません。想定外のパターンは、素通り。だから、条件をどう決め、見直すかが、命。複雑な判断は、AIや人に。
## S7（ld-07）
- テロップ：まず「毎回おなじ観点」を1つ
- ナレーション：まずは、自分の確認で、毎回おなじ観点でチェックしている所を、ひとつ。それは、ルールにできます。
