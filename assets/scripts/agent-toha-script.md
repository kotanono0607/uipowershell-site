# 台本：AIエージェントってなに？（用語シリーズ#7・実演版）

- 脱・概念の実演版。目的→計画→実行→送信前で承認待ち、を「やって見せる」。7シーン。
- 1メッセージ：AIエージェント＝目的を渡すと自分で段取りし操作するAI。便利だが発展途上。権限を絞り、要所で人の承認を挟む。

## S1（gd-01）
- テロップ：下書きAI → 自分で動くAIへ
- ナレーション：これまでのAIは、下書きまでが担当で、実行は人。でも次は、AIが、自分で画面を操作して、仕事を最後までやる世界です。
## S2（gd-02）
- テロップ：それがAIエージェント（M4第3段階）
- ナレーション：それが、AIエージェント。M4で出てきた、第3段階の、正体です。やって見せます。
## S3（gd-03 実演①）
- テロップ：自分で段取りを立てる
- ナレーション：たとえば、申請30件を集計して、メールで送って、と頼む。すると、エージェントは、自分で段取りを立てる。OCRで読む、Excelで集計、メールを作成、送信。
## S4（gd-04 実演②）
- テロップ：③まで、自分でこなす
- ナレーション：そして、3番目まで、自分でこなす。ツールを次々に操作して、ここまで一気に進めます。
## S5（gd-05 実演③）
- テロップ：送信の前で、承認を待つ
- ナレーション：でも、送信の前で、止まる。「このメールを送信してよいですか」と、人の承認を待つ。もし誤集計のまま送れば、事故。だから、要所で人が止めます。
## S6（gd-06）
- テロップ：まだ発展途上・暴走のリスク
- ナレーション：まだ、発展途上です。誤った操作や、暴走のリスクもある。だから、できる権限を絞って、要所で人の承認を挟むのが、鉄則です。
## S7（gd-07）
- テロップ：狭く・承認つきで・小さく
- ナレーション：いきなり、全部は任せない。狭い範囲で、承認つきで、小さく試す。それが、次の波の、安全な乗り方です。
