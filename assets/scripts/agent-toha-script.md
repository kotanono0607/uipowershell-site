# 台本：AIエージェントってなに？（用語シリーズ#7・深掘り版）

- 位置づけ：1動画＝1概念の深掘り。M4の「第3段階（エージェント化）」の正体を解く。AI回の続き＝「下書きするAI」の次。
- 題材軸：下書きまでのAI → 自分で操作するAI
- 1メッセージ：**AIエージェント＝目的を渡すと、自分で段取りしてツール・システムを操作し達成しようとするAI。便利だがまだ発展途上で、権限を絞り人の承認を挟むのが鉄則**
- 狙い：初心者に用語を教える（M4の予告編の回収）
- 尺：約2:10〜2:30（6シーン）／ナレーター：VOICEVOX ずんだもん（speaker 3）
- POV／持論：**「手を動かすAIの時代でも、手綱（権限と承認）は人が握る」**
- 深さ担保：定義（代理人）＋仕組み（目標→計画→操作→確認のループ）＋限界（暴走・権限管理）を必ず入れる。

---

## S1｜つかみ（図解 agent-01）
- テロップ：これまでのAIは「下書き」担当。でも次は—
- ナレーション：これまでのAIは、下書きまでが担当で、実行は人がしていました。でも、次に来るのは、AIが、自分で画面を操作して、仕事を最後までやってしまう世界です。

## S2｜用語の登場（agent-02）
- テロップ：M4の「第3段階」の正体
- ナレーション：それが、AIエージェント、エージェント化、と呼ばれるもの。M4で出てきた、第三段階の、正体です。

## S3｜定義（中心図解 agent-03）
- テロップ：エージェント＝代理人
- ナレーション：エージェントとは、代理人のこと。AIエージェントは、目的を渡すと、自分で段取りを考え、ツールやシステムを操作して、達成しようとするAIです。

## S4｜仕組み＝ループ（agent-04）
- テロップ：目標→計画→操作→確認 を自分で回す
- ナレーション：動き方は、ループです。目標を受け取り、計画を立て、ツールを操作し、結果を確認する。足りなければ、やり直す。この一連を、自分で回していきます。

## S5｜限界（agent-05）
- テロップ：まだ発展途上・暴走のリスク
- ナレーション：ただし、ここが大事。まだ、発展途上です。誤った操作や、思い込みで突き進む暴走の、リスクもある。だから、できる権限を絞って、要所で人の承認を挟むのが、鉄則です。

## S6｜行動喚起（締め agent-06）
- テロップ：狭く・承認つきで・小さく試す
- ナレーション：いきなり、全部を任せない。狭い範囲で、人の承認つきで、小さく試す。それが、次の波の、いちばん安全な乗り方です。
