## 「浅さ」対策＝用語シリーズ（実演版）の方針【新】
- 問題：M1〜M4は2分に全部詰め込むため「きれいだが浅い／AIっぽい」。原因＝1本に概念を詰め込み、用語を説明せず、ドリルダウンできていない。
- 解：**1動画＝1概念**に割る。各概念を「定義→仕組み→実例→限界→文脈／行動喚起」で**圧縮せず開く**。M1〜M4はそのまま“全体像”として残し、その中の用語を1つずつ深掘りする子シリーズを足していく。
- 取材ベース（grill-meで抽出した一次素材を必ず混ぜる）：軸業務＝紙/PDF→Excel転記／**ほぼ毎日**／1件5〜15分だが回数多い／事故＝**桁の写し間違い・重複抜け落ち**／現場対処＝**ダブルチェック・目視で気合い**／POV＝**「見て写すだけは人がやる仕事じゃない」**／狙い＝**初心者に用語を教える**。
- 深さチェックリスト：①固有名詞・数字がある ②やった人しか知らない一文がある ③間違えうる主張（限界）を必ず入れる ④出典の裏付け（参照は事実/数値の抽出のみ・言い回しは流用しない）⑤典型例の丸写しを避ける ⑥1動画1概念 ⑦用語を使う前に説明する。
- 【実演版に刷新（脱・概念）2026-05-25】「説明する」をやめ「やって見せる」へ。全8本、実物の値で操作・失敗・実害を見せる（例：OCRで125万円の「0」が「O」に化け→Excelが#VALUE!）。同じ申請書ケース（山田太郎・交付金額125万円）を全編で通す。旧・深掘り版/AIヒーロー画像版は置換。
