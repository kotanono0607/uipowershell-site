# 台本：AIでこれから何が変わる？ M4 実例図解版（推敲3・温度入れ）

- 1メッセージ：**AIは「段階」で来る。今の段階を知り、仕事を“渡せる形”に整えて次の波に備える**
- 尺：約1:35（目安・6シーン）／ナレーター：VOICEVOX ずんだもん（speaker 3）
- 毒の強度：中（敵＝紙前提／属人化／“前からこう”）
- ⚠ 同期状態：**台本=最新（推敲3）／動画 `m4-zukai.mp4`・モジュール本体ページ=旧のまま＝未反映**
- 推敲3の変更：各段階を具体で接地（テンプレ脱却）。「エージェント化」のバズを噛み砕く。S5で敵（紙/属人化/前からこう）に中強度で言及。動詞を「整える」で統一しオチのズレを解消。S2の弱腰（たぶん）を断定に。

---

## S1｜つかみ（図解 m4-z01）
- テロップ：AIで、仕事はどう変わる？
- ナレーション：これからAIで、仕事はどう変わるのか。いきなり全部、ではありません。三つの段階で、じわじわ来ます。少し、のぞいてみましょう。

## S2｜第1段階・今（ステッパー：第1ハイライト・要新規）
- テロップ：第1段階　人間中心
- ナレーション：今は、第一段階。人が中心で、定型作業の一部だけを、自動化している。多くの職場は、まだここです。

## S3｜第2段階・AI補助（ステッパー：第2ハイライト・要新規）
- テロップ：第2段階　AI補助
- ナレーション：次が、第二段階。AIが下書きや、振り分けを手伝い、人が最終チェックをする。たとえば、問い合わせの一次対応をAIが下書きし、人が直して返す。そんな、二人三脚です。

## S4｜第3段階・エージェント化（ステッパー：第3ハイライト・要新規）
- テロップ：第3段階　エージェント化
- ナレーション：そして第三段階。AIが、画面の操作や、複数システムをまたぐ処理まで、自分でこなす。“エージェント化”なんて言われますが、要は、人の代わりに手を動かすAI、のことです。

## S5｜波に乗るカギ（敵＝紙/属人化）（図解：AIに渡せる形に整える）
- テロップ：カギは「AIに渡せる形」
- ナレーション：ただ、波が来ても、土台がなければ乗れません。紙のまま、“前からこうだから”のまま、担当者の頭の中だけ、では、AIにも渡せない。だから今、仕事を「AIが扱える形」に整えておく人が、強いんです。

## S6｜締め＋行動喚起（図解：締めテロップ）
- テロップ：自分の段階を知ることから
- ナレーション：むずかしく考えなくて、大丈夫。まず、自分の職場が今どの段階かを、知る。そして、いちばん繰り返している作業から、AIに渡せる形に、整えておく。それが、次の波に乗る、確実な準備です。
