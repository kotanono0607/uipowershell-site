# 台本：どうやって自動化する？ M2 実例図解版（推敲3・温度入れ）

- 1メッセージ：**技術は単独で覚えない。人の作業に当てはめて選ぶ（ただし魔法ではない）**
- 尺：約1:30（目安・6シーン）／ナレーター：VOICEVOX ずんだもん（speaker 3）
- 毒の強度：中（敵＝二重入力文化）
- ⚠ 同期状態：**台本=最新（推敲3）／動画 `m2-zukai.mp4`・モジュール本体ページ=旧のまま＝未反映**
- 推敲3の変更：S5に「万能ではない」（OCR読み違い/RPA停止）を追加し“魔法化”を回避。敵＝二重入力文化に言及。締めに当人の利益（残業・気疲れ減）。S1の砕けすぎ（めまい）を調整。

---

## S1｜つかみ（図解 m2-z01）
- テロップ：専門用語が多くて難しそう？
- ナレーション：自動化と聞くと、RPA、OCR、AI。横文字が並ぶだけで、つい身構えてしまいますよね。ぜんぶ覚えなきゃ、と思うと、もう手が止まる。

## S2｜転換（m2-z02）
- テロップ：「人の仕事の代わり」で選ぶ
- ナレーション：でも、ぜんぶ覚える必要はありません。コツは、技術を「人の仕事の代わり」として選ぶこと。やっている作業を軸にすると、すっきり決まります。

## S3｜対応づけ（中心図解 m2-z03）
- テロップ：人の操作 → 技術
- ナレーション：人の操作に、技術を当てはめてみましょう。操作するならRPA、見るならOCR、考えるならAI、データを扱うならExcel、つなぐならAPI。作業の名前で選べば、迷いません。

## S4｜実例（敵＝二重入力）（m2-z06）
- テロップ：申請書 → Excel なら
- ナレーション：たとえば、同じ数字を、いくつものシステムに入れ直す“二重入力”。あれこそ、機械の出番です。見るのはOCR、打つのはRPA、確認はルール。さっきの当てはめが、そのまま効きます。

## S5｜万能ではない（新規スライド要）
- テロップ：技術は魔法じゃない
- ナレーション：ただし、技術は魔法ではありません。OCRが読み違える、画面が変わってRPAが止まる、ということもあります。だから最初は、人が確認しながら、小さく試す。それで十分です。

## S6｜締め＋利益＋行動喚起（m2-z07）
- テロップ：技術は怖くない
- ナレーション：それでも、当てはめて選べば、技術はもう怖くありません。二重入力や、確認地獄が減れば、残業も、気疲れも、軽くなる。まずは、自分の仕事のひとつから、組み合わせていきましょう。
