# 台本：どうやって自動化する？ M2 実例図解版（推敲済み）

## S1｜つかみ（図解 m2-z01）
- テロップ：専門用語が多くて難しそう？
- ナレーション：自動化と聞くと、RPA、OCR、AI。専門用語が並ぶと、難しそうに見えますよね。ぜんぶ覚えようとすると、めまいがします。

## S2｜転換（m2-z02）
- テロップ：「人の仕事の代わり」で選ぶ
- ナレーション：でも、ぜんぶ覚える必要はありません。コツは、技術を「人の仕事の代わり」として選ぶこと。やっている作業を軸にすると、すっきり決まります。

## S3｜対応づけ（中心図解 m2-z03）
- テロップ：人の操作 → 技術
- ナレーション：人の操作に、技術を当てはめてみましょう。操作するならRPA、見るならOCR、考えるならAI、データを扱うならExcel、つなぐならAPI。これだけです。

## S4｜深掘り（m2-z04）
- テロップ：読む・操作する・判断する
- ナレーション：それぞれが何をするか。OCRは文字を読み取る。RPAは画面操作を繰り返す。AIは内容を判断し、分類する。たとえば、問い合わせの仕分けですね。

## S5｜実例で確認（m2-z06）
- テロップ：申請書 → Excel なら
- ナレーション：では、実際に当てはめてみます。申請書をExcelに転記するなら、見るはOCR、入力はRPA、確認はルール。前回の例も、この考え方でできていたんです。

## S6｜締め＋行動喚起（m2-z07）
- テロップ：技術は怖くない
- ナレーション：このように、人の作業に当てはめれば、技術はもう怖くありません。まずは、自分の仕事のどれかひとつ。できる操作から、組み合わせていきましょう。
