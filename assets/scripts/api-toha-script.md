# 台本：APIってなに？（用語シリーズ#4・実演版）

- 脱・概念の実演版。手作業の写し間違い vs API直結を「やって見せる」。7シーン。
- 1メッセージ：API＝アプリ同士の受付窓口。手で写すとミスが混じるが、直結すれば値はそのまま届く。ただし両側の対応が要る。

## S1（ad-01）
- テロップ：システムをまたいで手入力していませんか？
- ナレーション：システムAの数字を、システムBに、また手で打ち直す。コピペの往復。その合間に、写し間違いも、まぎれ込みます。
## S2（ad-02）
- テロップ：つなぐ技術＝API
- ナレーション：このシステム同士の受け渡しを、人を介さず、直接やるのが、API。実際に、手作業と、比べてみます。
## S3（ad-03 実演①）
- テロップ：手作業だと、ミスが混じる
- ナレーション：まず、手作業。システムAの、125万円を、目で見て、システムBに入力。…と、最後のゼロが、ひとつ落ちました。見て写すと、ミスが混じります。
## S4（ad-04 実演②）
- テロップ：APIで直結＝ミスゼロ
- ナレーション：次に、APIで直結。システムAから、APIを通って、システムBへ。値はそのまま、125万円。打ち直しゼロ、ミスもゼロです。
## S5（ad-05）
- テロップ：API＝アプリ同士の受付窓口
- ナレーション：APIは、英語の頭文字。アプリケーション、プログラミング、インターフェース。つまり、アプリ同士の、受付窓口のことです。
## S6（ad-06）
- テロップ：両側の対応が要る
- ナレーション：ただし、APIは、相手が窓口を公開していないと使えません。仕様変更や、回数制限、認証も。どこへでも通じる、魔法の配線ではありません。
## S7（ad-07）
- テロップ：まず「2回打ってる所」を探す
- ナレーション：まずは、同じデータを、2つのシステムに手入力している場所を、探す。つながれば、打ち直しごと、消えます。
