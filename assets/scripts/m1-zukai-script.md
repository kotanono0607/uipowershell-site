# 台本（決定版・推敲）：業務の自動化とは？ M1 実例図解版

- 題材：申請書PDF → Excel 転記（具体実例）
- 型：①具体的な痛み → ②たった1つの気づき → ③今日からの一歩
- 1メッセージ：「複雑に見える仕事も、小さな操作に分ければ、機械に渡せる」
- 尺：約1:45（7シーン）／ナレーション：VOICEVOX ずんだもん（speaker 3）
- 文体：丁寧＋会話調（※ずんだもん口調〔〜なのだ〕版も別途用意可）

---

## S1｜痛み（手作業の現状）
- 映像：図解（申請書PDF →[手作業]→ Excel ／ ⏱時間・⚠ミス）
- テロップ：その転記、手作業でやっていませんか？
- ナレーション：
  PDFの数字を、ひとマスずつ、エクセルに打ち込む——。あの地味な作業、今日もありませんでしたか。時間はかかるし、ひとつ写し間違えると、確認からやり直し。地味だけど、けっこう、しんどいですよね。

## S2｜気づき（3つの操作に分解）
- 映像：図解（転記作業 → 見る／入力／判定）
- テロップ：でも、よく見ると3つの操作
- ナレーション：
  でも、ちょっと待ってください。この“めんどうな転記”、よく見ると、やっていることは、たった三つ。「見て」「打って」「確かめる」。それを、何十回も繰り返しているだけなんです。

## S3｜構造（入力→処理→出力＋技術）
- 映像：中心図解（INPUT申請書PDF → PROCESS 見る:OCR/入力:RPA/判定:ルール → OUTPUT Excel台帳）
- テロップ：分ければ、機械に任せられる
- ナレーション：
  つまりこの仕事は、申請書という「入力」を、見て・打って・確かめる「処理」で、エクセルという「出力」に変えているだけ。そして、その一つひとつには、ちゃんと“代わり”がいます。見るはOCR、打つはRPA、確かめるはルール。

## S4｜なぜ任せられる
- 映像：図解（小さな操作 → 手順＝ルール → 機械が繰り返す）
- テロップ：操作は「手順」が決まっている
- ナレーション：
  なぜ、任せられるのか。それは、分けた操作が、いつも「同じ手順」だからです。毎回おなじ場所を見て、おなじ場所に打つ。手順さえ決まっていれば、機械は何度でも、文句も言わず、正確に繰り返してくれます。

## S5｜見分け方（4チェック）
- 映像：図解（4チェックリスト）
- テロップ：自動化に向く仕事？ 4つでチェック
- ナレーション：
  では、自分の仕事は向いているのか。見分け方は、四つ。ルール通りに進む。同じことを繰り返す。例外がほとんどない。入力が、紙ではなくデジタル。当てはまるほど、自動化は、ぐっと近づきます。

## S6｜効果（before→after）
- 映像：図解（手作業:数分・ミス → 自動化:ほぼ一瞬・ミス激減 ※イメージ）
- テロップ：手作業 → 自動化
- ナレーション：
  任せると、どうなるか。これまで何分もかけていた転記が、ほんの一瞬で終わります。しかも、写し間違いは、ほぼゼロ。空いた時間は、人にしかできない仕事に、まわせます。

## S7｜一歩（締め）
- 映像：締め（まずは「分解」から）
- テロップ：まずは「分解」から
- ナレーション：
  むずかしい技術の名前は、後で大丈夫。第一歩は、自分の仕事を、小さく分けてみること。たった一つの作業、たった一つの操作から。そこから、ラクは、始まります。

## 推敲メモ（旧版からの改善点）
- フック強化：一般論「毎日の仕事は…」→ 具体的な痛み「PDFの数字をひとマスずつ…」
- 1メッセージに集約：複数フレームの羅列をやめ、「分ければ渡せる」一本に
- 言い回し：「文句も言わず正確に」「人にしかできない仕事にまわせる」等、記憶に残る語
- 締め：抽象的な標語 → 行動の最小単位（たった一つの操作から）
