# 台本：業務の自動化とは？ M1 実例図解版（推敲3・温度入れ）

- 題材：申請書PDF → Excel 転記
- 1メッセージ：**複雑に見える仕事も、小さく分ければ、機械に渡せる**
- 尺：約1:40（目安・6シーン）／ナレーター：VOICEVOX ずんだもん（speaker 3）
- 毒の強度：中（敵は「仕組み・文化」。個人/組織は責めない）
- ⚠ 同期状態：**台本=最新（推敲3）／動画 `m1-zukai.mp4`・モジュール本体ページ=旧のまま＝未反映**（方針：台本のみ更新）
- 推敲3の変更：痛みを身体感覚へ（午前が溶ける／ミスが怖い）。効果を“当人の利益”に（不安から解放）。締めに毒の問いかけ。S1の過去形を現在形に。

## S1｜痛み（図解 zk-01）
- テロップ：その転記、手作業でやっていませんか？
- ナレーション：申請書の数字を、ひとマスずつ、エクセルに打ち込む。気づけば、午前中がまるごと、転記で溶けている。ひとつ写し間違えれば、確認からやり直し。ミスが怖くて、気も抜けない。……ねえ、その作業、本当に、人がやる仕事でしょうか。

## S2｜気づき（zk-02）
- テロップ：でも、よく見ると3つの操作
- ナレーション：でも、ちょっと待ってください。この“めんどうな転記”、よく見ると、やっていることは、たった三つ。「見て」「打って」「確かめる」。それを、何十回も繰り返しているだけなんです。

## S3｜肩代わり（中心図解 zk-03）
- テロップ：分ければ、機械に任せられる
- ナレーション：そして、その三つには、ちゃんと“代わり”がいます。「見る」はOCRが読み取り、「打つ」はRPAが入力し、「確かめる」はルールでチェック。人がやっていた手順を、そのまま肩代わりしてくれます。

## S4｜なぜ任せられる（zk-06）
- テロップ：操作は「手順」が決まっている
- ナレーション：なぜ、任せられるのか。それは、分けた操作が、いつも「同じ手順」だからです。毎回おなじ場所を見て、おなじ場所に打つ。手順さえ決まっていれば、機械は何度でも、文句も言わず、正確に繰り返してくれます。

## S5｜効果（zk-08）
- テロップ：手作業 → 自動化
- ナレーション：任せると、どうなるか。転記は一瞬で終わり、写し間違いの不安から、解放されます。確認に追われる時間も、ミスにビクビクする緊張も、減っていく。空いたぶんは、人にしかできない仕事に、まわせます。

## S6｜一歩（締め zk-05）
- テロップ：まずは「分解」から
- ナレーション：むずかしい技術の名前は、後でかまいません。まずは、自分の仕事をひとつ、3つの操作に分けてみる。それだけで、自動化はもう始まっています。「これ、人がやらなくてもいいかも」——その一つを、見つけることから。
