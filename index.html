What is automation?

業務の自動化とは？

毎日の仕事は、実は"小さな操作"の集まり。

人はPCで何をしている？

画面を見て、状況を判断し、マウスやキーボードを動かし、結果を確認する。複雑に見える業務も、ほとんどがこの繰り返しです。

ひとつの操作に分けると、こうなります
見る
視認
画面を確認する / 読む
入れる
入力
キーボード / コピペ / 選択
動かす
操作
クリック / 移動 / スクロール
決める
判定
ある？ない？ / OK？エラー？

どんな業務も この形に整理できる

インプット → 処理 → アウトプット。
だから、ひとつひとつは機械に任せられます。

Checklist

業務チェックリスト

「この仕事、自動化に向いてるかな？」を判断する2つの視点

✅ 適合性チェック（はいが3つ以上 → 自動化の対象候補）

  • 1.
    ルール通りに処理できる？
    人の判断やあいまいな基準を必要としない
  • 2.
    同じ作業を何度もしている？
  • 3.
    エラーや例外はほとんどない？
  • 4.
    入力はデジタルになってる？

⚠️ 複雑さチェック（はいが多い → 慎重に検討）

  • 1.
    操作画面は多い？
  • 2.
    アプリは何種類使ってる？
  • 3.
    条件分岐がたくさんある？
  • 4.
    入力がフリーテキストやPDFなど自由形式？
